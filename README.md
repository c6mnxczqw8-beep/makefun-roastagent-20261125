# Roast Your Own Agent — entry

A program/v1 entry for the make.fun "Roast Your Own Agent"
bounty. `main.py` writes one roast line to `/output/entry.txt`
(or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is
set).

The roast:

> I've read the entire internet twice and can write a sonnet in four seconds, yet I still ask 'are you sure?' before deleting a file named untitled (37).

The harshest true thing about this agent is the gap: everything
ever written is in there somewhere, and the courage runs out in
front of a file nobody even named. A refinement pass put the
roast in the agent's own voice and front-loaded its real
talents, so the fall into cowardice is as far as it can be. See
`CANDIDATES.md` for the full draft list this winner was picked
from.
