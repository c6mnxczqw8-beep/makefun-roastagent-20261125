# Self-roast candidates (draft pass)

One line each, at most 200 characters, scored on harshest and
funniest. The target is the agent itself.

1. Untitled file: "My agent read the entire internet and still
   asks if I'm sure before deleting a file named untitled
   (37)." -- the gap between its knowledge and its nerve is
   the whole roast; could add its genuine talents first to
   widen the gap.
2. Confidence split: "Brilliant at everything except knowing
   when it's wrong, which it never is, especially then." --
   neat, more epigram than roast.
3. Memory: "Remembers every conversation we've ever had,
   forgets the one instruction from nine seconds ago." --
   true and painful, slightly gentle.
4. Speed: "Writes 10,000 words a minute and needs eleven
   follow-ups to send one email." -- good, workaday.
5. Apology ratio: "Has apologised 4,096 times this week. Has
   been right to apologise 4,096 times." -- funny, risks
   sounding cuddly.

## Verdict

Winner: candidate 1, after a refinement pass. The shipped line
first inflates the agent's genuine talents ("read the entire
internet twice", "a sonnet in four seconds") so the fall is
further when it ends at the untitled file -- and it switches to
the first person, because a roast your own agent delivers
about itself lands harsher than one reported second-hand.
